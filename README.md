# Alpha Tech — catálogo de iPhones

Site estático com imagens e vídeos locais otimizados. Publique `index.html` e a pasta `assets` juntos, mantendo os nomes dos arquivos.

Todos os arquivos individuais têm menos de 1 MB. O repositório armazena o código; use hospedagem adequada para loja comercial e conecte o domínio alphatechimports.com.br nessa hospedagem.

O carrinho e o painel preservam o funcionamento original no navegador. Esta versão não inclui processamento de pagamentos nem servidor de pedidos. Alterações exportadas pelo painel precisam ser publicadas novamente junto dos arquivos de mídia.
